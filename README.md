## Installation
```bash
python -m venv .venv
source .venv/bin/activate
pip install mkdocs-material
pip install neoteroi-mkdocs
pip install mkdocs-exporter
```
## Local development hot-reload
```bash
clear; python -m mkdocs serve --livereload --watch-theme
```
